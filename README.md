### 💼 Featured Projects

#### 🔎 [VeriGraph AI — Secure RAG Document Q&A System](https://github.com/Sourav-glitch-ctrl)
A secure, multi-turn document Q&A system with a FastAPI backend and a 6-node LangGraph pipeline (retrieve → rerank → generate), using BGE embeddings and ChromaDB. Includes a multi-provider LLM fallback gateway, two-tier API-key RBAC, and a quarantine-based ingestion pipeline for safe PDF/DOCX uploads.
`FastAPI` `LangGraph` `LangChain` `ChromaDB` `Streamlit` `Python` `RAG`

#### 📈 [Cryptocurrency Volatility Prediction](https://github.com/Sourav-glitch-ctrl/Cryptocurrency-Volatility-Prediction)
An end-to-end ML pipeline predicting crypto price volatility using OHLCV data, 10+ engineered technical indicators, and Scikit-learn classification models.
`Python` `Pandas` `Scikit-learn` `Matplotlib` `Feature Engineering` `EDA`

#### 🚦 Automatic Railway Gate Control System
An IoT-based automated railway gate system using ultrasonic sensors and GSM alerts to reduce accidents at unmanned level crossings.
`Arduino` `Ultrasonic Sensor` `GSM Module` `Embedded C` `IoT`
